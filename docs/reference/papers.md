# List of the contained papers

One row per bibliography entry in `data-raw/bib/papers.bib`. `BIBTEXKEY`
matches the `paper` column of
[catalog](https://kvasilopoulos.github.io/econdata/reference/catalog.md).

## Usage

``` r
papers
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 7
rows and 17 columns.
