# Kilian and Lütkepohl (2017) textbook oil VAR

Quarterly US oil-market data used in Chapter 2 of *Structural Vector
Autoregressive Analysis*: real oil price growth (`drpoil`), inflation
(`infl`) and real GDP growth (`drgdp`), 1973Q1-2013Q2.

## Usage

``` r
oil
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 162
rows and 4 columns.

## References

L. Kilian and H. Lütkepohl. \_Structural Vector Autoregressive
Analysis\_. Themes in Modern Econometrics. Cambridge: Cambridge
University Press, 2017. DOI: 10.1017/9781108164818.
\<https://doi.org/10.1017/9781108164818\>.
