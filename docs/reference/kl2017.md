# Kilian and Lütkepohl (2017) textbook monetary VAR

Quarterly US data used in Chapter 2 of *Structural Vector Autoregressive
Analysis*: real GDP growth (`drgdp`), federal funds rate (`ff`) and
inflation (`infl`), 1954Q4-2007Q4.

## Usage

``` r
kl2017
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 213
rows and 4 columns.

## References

L. Kilian and H. Lütkepohl. \_Structural Vector Autoregressive
Analysis\_. Themes in Modern Econometrics. Cambridge: Cambridge
University Press, 2017. DOI: 10.1017/9781108164818.
\<https://doi.org/10.1017/9781108164818\>.
